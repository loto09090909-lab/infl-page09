테마

페이지 색상/스타일 선택

방문자가 보는 사용자 페이지의 배경·버튼 색상을 미리 골라 적용하세요.

테마는 저장 후 실사용 페이지에도 즉시 반영됩니다.

슬러그

슬러그와 별칭 관리

페이지 주소를 원하는 이름으로 바꾸고, 여러 개의 별칭을 추가할 수 있습니다.

슬러그는 영어/숫자/하이픈으로 구성되며, 기존 주소도 계속 유지됩니다.

커스텀 도메인

도메인 연결 관리

브랜드 도메인을 연결해 공유 주소를 변경할 수 있습니다.

도메인을 추가하면 DNS 연결이 필요합니다. 실제 연결은 운영팀에 문의하세요.

프로필

페이지 정보 수정

이름과 설명, 프로필 이미지를 업데이트하면 공개 페이지에도 바로 반영됩니다.

링크

링크 관리

플랫폼을 선택해 기본 주소를 불러오고, ▲▼ 버튼 또는 드래그로 순서를 조정하세요.

자주 쓰는 채널은 플랫폼을 선택하고 고유 아이디만 입력하면 됩니다.

기타 링크는 전체 URL을 입력하고 필요하면 아이콘 이미지를 넣어주세요.
